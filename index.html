Importar

        
Prefira OFX; PDF e planilha também funcionam. O app evita duplicata e, se já existir cupom OCR da mesma compra, oferece mesclar (mantém os itens da nota).

      


      

        Como exportar do seu banco (toque para expandir)
        

          

            Prefira OFX (ou QFX). Não há conexão automática com o banco — você exporta o arquivo e importa aqui.
          

          
    
            
  • Nubank / Inter / C6 / PicPay — Extrato → Exportar OFX ou CSV
    • 
            
  • Itaú / Bradesco / Santander / BB — Extrato → Exportar OFX ou planilha
    • 
            
  • Cartão — fatura em PDF (texto) ou CSV
    • 
          

        

      


      

        
        
        
      


      

        

          

            
            
          

          

            Arraste um ou vários arquivos OFX / QFX
ou toque para escolher — vários extratos são mesclados na revisão
          

          

            
          

          

            Se o arquivo não aparecer na lista do celular, escolha “Todos os arquivos” / “Arquivos” e selecione o download
            (alguns bancos salvam como .txt ou sem extensão).
          

          
          

          

        


        

          

            
            
          

          

            Arraste um ou vários PDFs aqui
ou clique para escolher — pode selecionar vários arquivos de uma vez
          

          
          

        


        

          

            
            
          

          

            Arraste uma ou várias planilhas aqui
.xlsx, .xls ou .csv — vários arquivos na mesma conta
          

          

            
          

          
          

          

        

      

    


    
    

      

        
Categorias

        
Organize despesas e receitas. Use palavras-chave (ex.: coasa:50 = até R$ 50) para classificar sozinho. Tipos especiais (Investimento etc.): Config → Tipos.

      


      


      

        

          Regras automáticas de categoria
          ▶
        

        


        

          Além das palavras-chave da categoria, você pode criar regras com faixa de valor.
          Ex.: descrição contém “farmácia” e valor entre 50 e 500 → Saúde.

Nuvem GitHub (Gist)

        

          Backup na nuvem num Gist secreto. Use o mesmo token e Gist ID nos aparelhos;
          cada um com um nome (ex.: iPhone, Notebook). Token: GitHub → Settings → Developer settings → Personal access tokens
          (permissão gist).
        

        

          

            
            
          

          

            
            
          

          

            
            
          

        

        

          Nos dois aparelhos: mesmo token + mesmo Gist ID. O nome aparece no backup para saber de qual dispositivo veio.
